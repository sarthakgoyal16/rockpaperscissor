# Rock Paper Scissors

A simple Rock Paper Scissors game where you play against the computer, built with HTML, CSS, and vanilla JavaScript.

## Features

- Play against a computer that picks randomly
- Live scoreboard for **YOU** and **COMP**
- Color-coded result messages (green for a win, red for a loss, black for a draw)
- Hover effect on the choice buttons
- Clean, minimal layout

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```
├── index.html     # Game markup
├── style.css      # Styling
├── script.js      # Game logic
├── ROCK.png       # Rock image
├── PAPER.png      # Paper image
└── SCISSOR.png    # Scissor image
```

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or build step is needed.

## How to Play

1. Click **Rock**, **Paper**, or **Scissor**.
2. The computer picks its move at random.
3. The winner is decided by the classic rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
4. The scoreboard updates after every round.
